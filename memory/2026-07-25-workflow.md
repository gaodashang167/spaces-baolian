# 代码修改成功记录规范

每次代码修改成功后，记录以下信息：

## 1. 改了什麼
- 具体改了什么文件、什么内容
- 改动前后的对比

## 2. 为什么成功
- 关键思路是什么
- 解决了什么问题
- 核心原因

## 3. 遇到什么问题
- 排查过程
- 踩过的坑
- 错误原因

## 4. 通用模式
- 以后遇到类似问题怎么参考
- 可复用的思路/步骤
- 注意事项

## 5. 参考文件
- 重要的基准版本位置
- 相关文件路径

---

## 示例：Cloudflare Snippets 代理 Worker 裁剪（2026-07-25）

### 1. 改了什麼
- 从 59KB 原版删除 TlsClient/TURN/SSTP 模块
- 保留 relay/matchID + chainConnect + PROXYIP fallback
- 最终 ~18KB

### 2. 为什么成功
- 保留了完整的核心链路逻辑
- CFG.concur=1 避免子请求配额耗尽
- CFG.dproxy 设了兜底代理域名
- UUID 与客户端匹配

### 3. 遇到什么问题
- 之前 UUID 不匹配（e3 vs e9）导致 relay 校验失败
- concur 默认值导致子请求配额耗尽
- 测试方法不对（浏览器/curl 无法触发 WebSocket 隧道）

### 4. 通用模式
- 确认运行时能力 → 精确删除模块 → 保留核心链路 → 调优 CFG → 验证语法 → 匹配 UUID
- 测试必须用真实客户端

### 5. 参考文件
- 基准版本：`最新通用.js`（Snippets 能跑通）
- 部署地址：GitHub raw + commit hash
